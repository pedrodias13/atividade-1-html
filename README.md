Minha primeira página HTML

Sobre o projeto

Este projeto foi desenvolvido como parte da Atividade 1 do curso Técnico em Informática para Internet.

A página apresenta uma estrutura HTML básica, com um título e parágrafos de texto.

Tecnologias utilizadas

- HTML5
- Chrome DevTools para testar uma alteração temporária de CSS

Arquivo principal

- "index.html": contém o código-fonte da página web.

Objetivo

Praticar os primeiros conceitos de desenvolvimento web, compreender a estrutura básica do HTML e conhecer as ferramentas de desenvolvedor do navegador.
